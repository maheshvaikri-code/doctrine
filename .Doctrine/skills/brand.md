# Skill: Brand

**Scope.** Identity, voice, narrative, and category — the widest marketing
frame, above positioning sentences (`skills/marketing.md`) and visual craft
(`skills/web-design.md`). Everything outbound is a draft; the human sends.

## Principles
- A brand that is not written down is not a brand, it is each author's
  taste. Voice attributes, banned claims, and the sentences the company
  will not say belong in a file a review can fail a draft against.
- The narrative is about the world, not the product: name the change you
  believe is happening and where the reader already stands in it. The
  product enters as the consequence, never as the premise.
- Consistency compounds and novelty resets. A good-enough identity held
  steady outperforms a better one restated every quarter, because
  recognition is built by the repetition the team tires of first.
- Brand is authored, reputation is earned. You write the claim, the
  audience returns the verdict, and every gap between the two is a debt
  that comes due at the least convenient moment.
- Entering a category is cheap; creating one is paid for in education.
  Create only when no existing category holds the product without a lie,
  and expect the bill to land on the buyer's comprehension.

## Defaults
- A brand file on record: the narrative in one paragraph, the audience,
  three voice attributes each with a do and a don't example, and the
  claims this brand may not make.
- Voice is testable or it is vague: a draft passes when the file's own
  examples classify it correctly. If two reviewers disagree, the file is
  at fault, not the draft.
- Brand claims are re-read against the shipped product every release. A
  capability the product no longer has leaves the brand file the same
  day, on the honesty law, not at the next brand refresh.
- Naming runs a check before it runs a vote: pronounceable, spellable
  from hearing, searchable, and free in the namespaces that matter.
  Trademark clearance is counsel the human obtains (`roles/legal-ops.md`).
- The brand file is internal; every expression of it is a draft queued
  for the human (.Doctrine.md §5). This skill never posts, renames a
  public surface, or registers anything.

## Do
- Write the narrative before the tagline. A tagline compresses a story
  that already exists; compressing nothing yields a slogan.
- Name what the brand is against — the status quo, the default tool, the
  tradeoff everyone accepts. A brand opposing nothing describes nothing.
- Version the brand file and record why each change happened, so drift
  is a readable decision rather than an accident nobody owns.
- Hand visual expression to the Web Designer with the brand file as input
  (`skills/web-design.md`, `roles/web-designer.md`). This skill decides
  what is said; that one decides how it looks.

## Don't
- Don't claim a value the product's behavior contradicts; users audit the
  brand with the software, not with the copy.
- Don't rebrand to fix a narrative problem; a new logo repaints a story
  nobody believed and buys silence, not belief.
- Don't invent a category to escape a comparison — the buyer relocates
  the comparison anyway, and now distrusts the framing too.
- Don't let voice override clarity in errors, docs, or UI text, and don't
  build a voice that dies in translation (`skills/i18n.md`).
- Don't grade brand on reach alone; unaided mention and the words people
  repeat back are the signal (`skills/metrics.md`).

## Review checklist
- [ ] Brand file exists: narrative, audience, voice examples, banned claims
- [ ] Narrative names a change in the world; the product is the consequence
- [ ] Every brand claim traces to shipped behavior; none contradicted by it
- [ ] Category choice justified: entry, unless entry requires a lie
- [ ] Name checked for sound, search, namespace; legal routed to the human
- [ ] Visual expression delegated; outbound expressions queued as drafts

## Common failure modes
The rebrand that repaints a story nobody believed; a category invented to
dodge a comparison the buyer makes anyway; voice attributes so generic
that no draft can fail them; claims outliving the capability that earned
them; consistency abandoned the moment the team tires of it, long before the
audience would have.
